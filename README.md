# דאשבורד לניהול לידים חכם

פרויקט הדגמה לימודי: דאשבורד סטטי בעברית לניהול לידים בעסק קטן. כל הנתונים פיקטיביים.

> **סטטוס:** תצוגה לקריאה בלבד: כרטיסים, תרשים, טבלה, סימון איחור ודירוג. עדיין אין חיפוש, סינון, הוספה, עריכה ושמירה. הנתונים נוצרים מחדש בכל טעינה.

## ענפים ותלות זמנית

| ענף | נוצר מתוך | תוכן |
| --- | --- | --- |
| `main` | - | מסמכים בלבד |
| `test/setup` | `main` | תשתית בדיקות |
| `feature/logic-core` | `test/setup` | שכבת הלוגיקה ונתוני הדמה |
| `feature/dashboard-view` | `feature/logic-core` | תצוגה לקריאה בלבד |

הענפים בנויים כשרשרת: כל ענף נוצר מהקודם ולא מתוך `main`. זה חריג זמני ומאושר לכלל ב-`Practice.md` (סעיף 3), כי הענפים הקודמים עוד לא מוזגו ל-`main`. כל ענף תלוי בקודם לו, ולכן ממזגים לפי הסדר: `test/setup`, אחריו `feature/logic-core` ואחריו `feature/dashboard-view`. אחרי המיזוג חוזרים ליצור ענפים מתוך `main`.

## הרצה מקומית

הקוד נטען כ-ES modules, ולכן צריך שרת סטטי ולא פתיחה ישירה של הקובץ:

```bash
npm install
npx serve .
```

ואז פותחים בדפדפן את `http://localhost:3000`.

## בדיקות

```bash
npm install
npx playwright install chromium
npm test          # בדיקות לוגיקה
npm run test:ui   # בדיקות ממשק, מחשב וסלולרי
npm run test:all  # הכל
```
